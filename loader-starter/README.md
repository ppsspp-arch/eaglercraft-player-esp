# Eaglercraft 26.3 Loader Starter — NOT A WORKING LOADER

This separate package is intentionally a **loader-identification starter**, not an executable loader. It will not install a loader into Eaglercraft or load mods.

The exact loader/API used by the target Eaglercraft 26.3 client has not been identified. A real loader package must be sourced from its legitimate project, checked for version compatibility, and packaged according to its own license and installation format.

## What is needed to make a real loader ZIP

- The exact loader name and official source/repository.
- Confirmation that it supports Eaglercraft 26.3.
- Its documented mod API and installation/package format.
- Permission to redistribute it, if the ZIP is to contain loader binaries.

Once those are verified, this starter can be replaced with a real loader distribution or a compatible integration package.
